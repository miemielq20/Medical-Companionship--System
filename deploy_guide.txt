## 三、前端部署（mc_ui 管理后台）

### 上传文件
将 mc_ui\dist\ 目录下所有文件上传到 /www/wwwroot/mc_ui/

### 宝塔操作
1. 网站 → 添加站点
   - 域名：124.220.16.162
   - 根目录：/www/wwwroot/mc_ui
   - PHP版本：纯静态

2. 设置 → 配置文件，替换为以下内容：
```
server {
    listen       80;
    server_name  124.220.16.162;

    location / {
        root   /www/wwwroot/mc_ui;
        index  index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    # 反向代理 /api 到后端 8080
    location /api {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        root   /www/wwwroot/mc_ui;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

## 七、重要注意事项

### 后端启动命令（务必带 prod 参数）
java -jar mc_server-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod

### Nginx 反向代理关键配置
location /api 中的 proxy_pass 后面不能带斜杠！
错误：proxy_pass http://127.0.0.1:8080/;
正确：proxy_pass http://127.0.0.1:8080;

带斜杠会去掉 /api 前缀，导致后端无法匹配接口。
